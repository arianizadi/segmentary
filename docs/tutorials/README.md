# Tutorials

Read these in order for a first project:

1. [Installation](installation.md) — choose a matching PyTorch build, install
   Segmentary, and verify imports/entry points.
2. [Getting started](getting-started.md) — scaffold a portable project, author
   labels, verify paired data, overfit eight images, train, and evaluate.
3. [Core concepts](core-concepts.md) — understand label spaces, mappings, active
   masks, stages, checkpoint handoff, EMA, tuning, and fair evaluation.
4. [Interpreting results and debugging](interpreting-results.md) — understand
   metric scales and diagnose data, model, optimization, and protocol failures.

The tutorials teach one safe path. The [guides](../README.md) explain alternatives
and advanced settings once that path works.
